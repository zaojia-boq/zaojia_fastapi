# 界面风格实验室（4 套方案对比）

单文件原型：`index.html`，双击即可在浏览器打开，无需安装任何环境、无外部 CDN 依赖。

> 用途：在动工写 Odoo 模块前，先把界面观感与操作流程定下来。
> 数据是模拟的，不连接数据库，仅用于看效果与评审。

## 参考来源

站酷作品《20 个特别精美的后台管理页面设计》（小蝶设计工作室）
文字版：https://m.zcool.com.cn/article/ZMTEwNTgyNA==.html

从 20 个案例中归纳出 4 条可复用的流派，各取一派落地为本项目的 4 套方案。

## 页面结构（8 页，与既有 demo 一致）

数据概览 / 清单检索 / 单价分析 / 导入向导 / 批次管理 / 物料字典 / 匹配确认 / 系统设置

关键业务细节已体现在原型里：

- 清单编码按 **前 9 位（国标清单码）+ 后 3 位（顺序码）** 分色显示
- 导入向导第 3 步展示编码解析结果：12 位标准 / 11 位补前导 0 / 10 位截取 / 9 位规范
- 匹配确认页体现「召回不自动改写数据，须人工确认后回填」原则
- 物料字典三级树 + 规格白名单 + 业务同义词

## 实现方式

同一套 DOM + 4 组设计 Token，通过 `<html data-theme="a|b|c|d">` 切换。
全部颜色走 CSS 变量，组件内不写裸色值 —— 与 M1.5 设计系统（Odoo primary variables bundle）的思路一致，
后续落地 Odoo 时，这 4 组 token 可直接映射为 4 套 SCSS 变量。

## 自检

```
python check.py
```

检查项：内联 JS 语法（node --check）、DOM 引用完整性、页面路由一致性、
4 套主题 token 完整性、关键类是否出现裸色值。
