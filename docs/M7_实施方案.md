### 任务 2.3　指标匹配纯函数（1.5 天）

**新文件**：`data/indicator_matcher.py`（纯函数，不依赖 SQLAlchemy，可单测）

```python
def match_indicator(
    item_name: str,
    item_feature: str,
    gb_code_9: str,
    qd_dict: list[dict],  # 内存中加载的 182 条 QD 字典
    e_dict: list[dict],   # 65 条 E 字典
) -> tuple[str, str, str, str]:
    """
    返回 (e_code, q_code, d_code, level)
    level: qd分类级 / e分部级回退 / unmatched
    匹配优先级：
      1. gb_code_9 前4位命中 qd_dict.gb_prefix
      2. item_name 命中 qd_dict.keywords
      3. E级回退（q_code=d_code=e_code）
      4. unmatched
    """
```

**测试**：`pure_tests/test_indicator_matcher.py`，拿云溪华庭 496 条重跑，与已有输出对比，E 级匹配率 ≥95%。

**验收**：纯函数无框架依赖；测试覆盖精确/前缀/回退/无匹配四种。

### 任务 2.4　指标计算 Service（1.5 天）

**新文件**：`app/services/indicator_service.py`

```python
def compute_batch_indicators(db: Session, batch_id: int):
    """导入确认后调用：
    1. 遍历该 batch 的所有 active boq_item
    2. 每条调 match_indicator → 回填 e_code/q_code/d_code/indicator_level
    3. 按 e_code 聚合：sum(total_num) → 单方造价 = 合价/building_area
    4. 按 q_code 聚合：sum(quantity_num), sum(单价*工程量)/sum(工程量) → 加权单价
    5. 结果写回 import_batch.e_summary / qd_summary / indicator_status='done'
    """
```

**改 `app/services/import_service.py`**：导入确认入库成功后，调用 `compute_batch_indicators(db, batch_id)`（同步跑，一个 batch 几百条很快，不需要异步队列）。

**改导入向导**：`app/api/import_api.py` 加一步——填建筑面积 `building_area`（必填，校验 >0 且 <1000000）。

**验收**：导入云溪华庭结算清单，自动算出 31 E + 38 QD，单方造价与 Excel 版误差 <1%。
