## 核心概念速查

- **E 编码**：经济指标编码，用于按分部汇总合价
- **Q 编码**：工程量指标编码，用于汇总物理工程量
- **D 编码**：单价指标编码，用于计算分部加权平均单价
- **Q×D≈E**：偏差校验公式，偏差率 = ABS(Q×D − E) ÷ E × 100%
- **建筑面积 S**：全部指标的核心分母，不可为 0
- **V6 编码方案**：对齐湘标 2.0，8 位编码，E/Q/D 三套独立
- **DB11/T 1711-2019**：建设工程造价技术经济指标采集标准
