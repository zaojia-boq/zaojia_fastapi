# 核心算法与公式

> E 经济指标 / Q 工程量指标 / D 单价指标 计算公式、精度要求、偏差校验
> 标准依据：DB11/T 1711-2019《建设工程造价技术经济指标采集标准》3.0.4

---

## 一、核心公式总览

```
E（经济指标，元/㎡） = 分部总合价 ÷ 建筑面积 S
Q（工程量指标，单位/㎡） = 分部总工程量 ÷ 建筑面积 S
D（单价指标，元/单位） = 分部总合价 ÷ 分部总工程量（加权平均）

校验：Q × D ≈ E（偏差率 ≤ 1% 合格）
```

---

## 二、E 经济指标（按 E 编码分组）

### 计算公式

```
分部合价 = Σ(该 E 编码下所有清单的合价)
经济指标（元/㎡） = 分部合价 ÷ 建筑面积 S
占总造价比例 = 分部合价 ÷ 项目分部分项总合价 × 100%
```

### 精度要求（DB11 3.0.4）

| 指标 | 精度 | 说明 |
|---|---|---|
| 经济指标 | 保留 2 位小数 | 单位：元/㎡ |
| 占比 | 保留 4 位小数后转为百分比 | 如 0.2235 → 22.35% |
| 分部合价 | 保留 2 位小数 | 单位：元 |

### 示例

```
钢筋工程（E=5AEGFJBS）：
  分部合价 = 5,343,600 元
  建筑面积 S = 12,000 ㎡
  经济指标 = 5,343,600 ÷ 12,000 = 445.30 元/㎡
  项目分部分项总合价 = 23,904,000 元
  占比 = 5,343,600 ÷ 23,904,000 = 0.2235 → 22.35%
```

## 三、Q 工程量指标（按 Q 编码分组）

### 计算公式

```
分部总工程量 = Σ(该 Q 编码下所有清单的工程量)
工程量指标 = 分部总工程量 ÷ 建筑面积 S
```

### 精度要求（DB11 3.0.4）

| 指标 | 精度 | 说明 |
|---|---|---|
| 工程量指标 | 保留 3 位小数 | 单位：原清单单位/㎡ |
| 分部总工程量 | 保留 3 位小数 | 单位：原清单单位 |

### 指标单位

| 原清单单位 | 工程量指标单位 | 示例 |
|---|---|---|
| t（吨） | t/㎡ | 钢筋：0.125 t/㎡ |
| m³（立方米） | m³/㎡ | 混凝土：0.456 m³/㎡ |
| ㎡（平方米） | ㎡/㎡ | 楼地面：0.850 ㎡/㎡ |
| m（米） | m/㎡ | 管线：1.234 m/㎡ |
| 个/套/樘 | 个/㎡ | 门窗：0.012 个/㎡ |

### 多计量单位处理

- 同一 Q 编码下存在多种计量单位时，取合价占比最大的单位汇总
- 其他单位的工程量单独列示，不纳入主单位汇总
- 在备注栏说明多计量单位情况

### 示例

```
钢筋工程（Q=5AQGJBS）：
  分部总工程量 = 1,500 t
  建筑面积 S = 12,000 ㎡
  工程量指标 = 1,500 ÷ 12,000 = 0.125 t/㎡
```

## 四、D 单价指标（按 D 编码分组，加权平均）

### 计算公式

```
分部总合价（D 组） = Σ(该 D 编码下所有清单的合价)
分部总工程量（D 组） = Σ(该 D 编码下所有清单的工程量)
加权平均单价指标 = 分部总合价 ÷ 分部总工程量
```

### 为什么用加权平均？

- 简单平均（各清单单价求和 ÷ 数量）会被小工程量清单的异常单价扭曲
- 加权平均（总合价 ÷ 总工程量）反映真实的平均单价水平
- 与 E/Q 校验公式 Q×D≈E 保持一致

### 精度要求（DB11 3.0.4）

| 指标 | 精度 | 说明 |
|---|---|---|
| 单价指标 | 保留 2 位小数 | 单位：元/原清单单位 |
| 分部总合价 | 保留 2 位小数 | 单位：元 |
| 分部总工程量 | 保留 3 位小数 | 单位：原清单单位 |

### 示例

```
钢筋工程（D=5ADGJBS）：
  分部总合价 = 5,343,600 元
  分部总工程量 = 1,500 t
  加权平均单价 = 5,343,600 ÷ 1,500 = 3,562.40 元/t
```

## 五、Q×D≈E 偏差校验

### 校验公式

```
理论经济指标 = Q × D
偏差率 = |理论经济指标 - 实际经济指标| ÷ 实际经济指标 × 100%
       = |Q×D − E| ÷ E × 100%
```

### 三级判定

| 偏差率 | 判定 | 处理 |
|---|---|---|
| ≤ 1% | ✅ 合格 | 正常通过 |
| 1% ＜ 偏差 ≤ 5% | ⚠️ 注意 | 备注说明（存在多计量单位混合统计） |
| ＞ 5% | ❌ 异常 | 回溯原始清单，检查 E/Q/D 编码挂接是否错误、分组口径是否不一致 |

### 偏差产生的常见原因

1. **多计量单位混合**：同一 D 编码下存在多种计量单位，加权平均单价口径不一致
   - 处理：不修改原始数据，只在备注写明"本分部包含多类计量单位，加权平均单价存在口径偏差"

2. **编码挂接错误**：E/Q/D 编码分配错误，导致分组口径不一致
   - 处理：回溯检查编码挂接，修正错误编码

3. **分组口径不一致**：E 编码分组范围与 Q/D 编码分组范围不同
   - 处理：检查编码字典，确保同名称分部的 E/Q/D 编码分组范围一致

4. **合价计算误差**：清单合价 = 工程量 × 综合单价 的累计误差
   - 处理：检查合价校验（误差 > 0.5% 的异常清单行）

### 示例

```
钢筋工程：
  Q = 0.125 t/㎡
  D = 3,562.40 元/t
  Q × D = 0.125 × 3,562.40 = 445.30 元/㎡
  E（实际） = 445.30 元/㎡
  偏差率 = |445.30 − 445.30| ÷ 445.30 × 100% = 0% ✅ 合格

混凝土工程（多计量单位）：
  Q = 0.456 m³/㎡（主单位 m³）
  D = 568.50 元/m³（加权平均，含 m³ 和套）
  Q × D = 0.456 × 568.50 = 259.24 元/㎡
  E（实际） = 259.25 元/㎡
  偏差率 = |259.24 − 259.25| ÷ 259.25 × 100% = 0.004% ✅ 合格
  备注：本分部包含多类计量单位（m³/套），加权平均单价存在口径偏差
```

## 六、数据清洗与校验

### 合价校验

```
计算合价 = 工程量 × 综合单价
误差率 = |实际合价 − 计算合价| ÷ 计算合价 × 100%
误差率 > 0.5% → 标记异常清单行
```

### 无效行过滤

- 空行：所有字段为空
- 合计行：项目名称含"合计""总计""小计"
- 备注行：项目名称含"注：""说明：""备注："
- 只保留有效分部分项清单条目

### 字段标准化

- 项目名称：去除前后空格、统一全角/半角
- 项目特征：去除前后空格、统一分隔符
- 计量单位：修正大小写（如 M3→m³）、去除空格、统一符号

### 数据类型转换

- 工程量：转为数值（float），非数值标记异常
- 综合单价：转为数值（float），非数值标记异常
- 合价：转为数值（float），非数值标记异常

---

## 七、异常处理规则

| 异常场景 | 处理方式 |
|---|---|
| 清单合价和工程量为 0 | 标记，不参与指标汇总 |
| 分部下多种计量单位 | D 编码分组产生偏差>5%时，不修改原始数据，备注说明原因 |
| 找不到匹配编码 | 不强行统计，人工补充 V6 编码字典后再运行流程 |
| 建筑面积 S 为 0 | 终止计算，抛出错误"建筑面积 S 不可为 0，是全部指标的分母" |
| 合价误差 > 0.5% | 标记异常清单行，人工复核 |
| 未匹配 E/Q/D 编码 | 标记【待补编码】，人工复核，不允许空编码进入统计 |
