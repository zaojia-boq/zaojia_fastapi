## 二、纯函数层复用（data/）

### 2.1 field_spec.py — 字段分层定义
- **内容**：A/B/C 字段分层常量（A 21/B 6/C 10）+ B_DEFAULTS + DATA_SOURCE_TYPES + PRICE_STAT_TYPES
- **M5 复用点**：
  - 指标生成时识别哪些字段可从清单数据提取（A 类）
  - B 类字段（人工标注）在指标生成时的保护规则
  - 数据性质（data_source_type）影响指标统计口径
- **复用方式**：直接 import 调用，零修改

### 2.2 aliases.py — 表头别名映射
- **内容**：Excel 表头别名映射（项目名称/项目特征/计量单位/工程量/综合单价/合价等）
- **M5 复用点**：
  - 指标生成时从原始 Excel 提取清单数据，复用表头别名映射
  - 字段映射模板（M2 深化）可直接复用
- **复用方式**：直接调用 map_headers() 函数

### 2.3 unit_normalize.py — 单位归一化
- **内容**：计量单位标准化（M3→m³、M2→㎡、M→m、t/T 统一等）
- **M5 复用点**：
  - Q 工程量指标计算时，单位标准化是前提
  - 多计量单位识别和处理
  - 指标单位（原清单单位/㎡）的标准化输出
- **复用方式**：直接调用 normalize_unit() 函数

### 2.4 price_calc.py — 单价计算纯函数
- **内容**：单价计算、加权平均、统计聚合
- **M5 复用点**：
  - D 单价指标的加权平均计算（核心算法）
  - E 经济指标的合价汇总
  - 单价趋势分析（可扩展）
- **复用方式**：直接调用加权平均函数，新增指标计算封装

### 2.5 quality_metrics.py — 质量指标纯函数
- **内容**：数据质量评分、异常检测、统计指标
- **M5 复用点**：
  - 偏差校验（Q×D≈E）的异常判定逻辑
  - 数据清洗阶段的异常检测
  - 指标质量评分
- **复用方式**：复用异常检测算法，新增偏差校验函数

### 2.6 tfidf_matcher.py — TF-IDF 语义匹配
- **内容**：TF-IDF 向量化 + 余弦相似度匹配
- **M5 复用点**：
  - V6 编码匹配时的语义匹配（项目名称+特征 → 编码）
  - 编码字典的模糊匹配
  - 与 rapidfuzz + FAISS 三算法融合（复用 M3 匹配框架）
- **复用方式**：直接调用 match() 函数，编码字典作为匹配库

### 2.7 learning_engine_v3.py — 学习引擎 v3
- **内容**：概念漂移检测、多策略集成、学习轨迹可解释、主动学习优化、元学习自动调参
- **M5 复用点**：
  - 编码匹配结果的学习反馈（人工复核 → 调整匹配权重）
  - 编码匹配准确率的持续优化
  - 主动学习：优先推荐高价值待补编码项
- **复用方式**：复用学习引擎框架，新增编码匹配学习模块

## 三、服务层复用（app/services/）

### 3.1 material_match_service.py — 物料匹配服务
- **内容**：三算法融合（rapidfuzz+TF-IDF+FAISS）+ 学习引擎权重自适应 + 候选推荐 + 人工确认
- **M5 复用点**：
  - V6 编码匹配的完整流程（候选推荐 → 置信度排序 → 自动确认 → 人工复核）
  - 三算法融合框架（编码字典作为匹配库）
  - 学习引擎集成（编码匹配结果反馈学习）
  - 后台预匹配机制（导入完成后异步计算编码匹配）
- **复用方式**：复用匹配算法框架，新增 code_match_service.py，编码字典替代物料字典

### 3.2 prematch_service.py — 后台预匹配服务
- **内容**：导入完成后异步计算匹配结果，缓存到 match_cache 表
- **M5 复用点**：
  - 编码匹配的后台预计算（导入完成后异步分配编码）
  - 匹配结果缓存（编码匹配结果缓存，避免重复计算）
  - 异步任务框架
- **复用方式**：复用预匹配框架，新增编码预匹配缓存表

### 3.3 price_service.py — 单价分析服务
- **内容**：同类项聚合统计、KPI 计算、单价趋势分析
- **M5 复用点**：
  - 按编码分组聚合统计的框架
  - KPI 计算逻辑
  - 数据查询和过滤
- **复用方式**：复用聚合统计框架，新增 indicator_calc_service.py

### 3.4 data_quality_service.py — 数据质量服务
- **内容**：异常标记、质量评分、待处理清单
- **M5 复用点**：
  - 偏差校验的异常标记和分类
  - 异常项回溯根因分析
  - 质量仪表盘（可扩展指标质量展示）
- **复用方式**：复用异常处理框架，新增 deviation_check_service.py

### 3.5 query_service.py — 查询服务
- **内容**：清单查询、筛选、分页、导出
- **M5 复用点**：
  - 指标生成时的清单数据查询（按批次/项目筛选）
  - 数据导出框架（多 Sheet Excel 导出）
  - 查询参数处理
- **复用方式**：复用查询和导出框架，新增 indicator_export_service.py

## 四、模型层复用（app/models/）

### 4.1 boq_item.py — 清单项目模型
- **内容**：44 列，含 A/B/C 分层标注、外键 RESTRICT、声明式复合索引
- **M5 复用点**：
  - 指标生成的数据源（直接查询 boq_item 表）
  - 字段定义（项目名称/特征/单位/工程量/单价/合价）
  - 数据性质（data_source_type）过滤
- **复用方式**：直接使用，无需修改

### 4.2 import_batch.py — 导入批次模型
- **内容**：23 列，含批次信息、校验和、状态
- **M5 复用点**：
  - 一个批次对应一个单位工程，可选择批次生成指标
  - 批次元数据（工程名称、建筑面积等）可扩展
  - 批次状态管理
- **复用方式**：扩展建筑面积等字段，关联指标生成结果

### 4.3 material_dict.py — 物料字典模型
- **内容**：13 列，三级树自引用
- **M5 复用点**：
  - V6 编码字典的树状结构参考
  - 编码分类管理框架
  - 全局共享机制
- **复用方式**：参考模型设计，新增 v6_code.py 编码表

### 4.4 audit_log.py — 审计日志模型
- **内容**：12 列，append-only 事件监听
- **M5 复用点**：
  - 指标生成/修改/导出操作的审计记录
  - 四元组（operator/reason/trace_id/timestamp）
  - append-only 机制
- **复用方式**：直接使用，无需修改

### 4.5 新增模型规划

| 模型 | 说明 | 依赖 |
|---|---|---|
| v6_code.py | V6 编码字典表（E/Q/D 三套编码，支持版本化管理） | 无 |
| project_meta.py | 项目元数据表（建筑面积 S、工程类型、结构类型等） | import_batch |
| indicator_result.py | 指标生成结果表（E/Q/D 指标汇总、偏差校验结果） | boq_item + v6_code + project_meta |
| code_match_cache.py | 编码匹配缓存表（预匹配结果缓存） | boq_item + v6_code |

## 八、复用率估算

| 模块 | 新增代码量 | 复用代码量 | 复用率 |
|---|---|---|---|
| 纯函数层（indicator_calc/v6_code_dict/data_cleaning） | ~800 行 | ~500 行（aliases/unit_normalize/price_calc/quality_metrics/tfidf_matcher/learning_engine） | 38% |
| 服务层（code_match/indicator_calc/deviation_check/indicator_export） | ~1200 行 | ~800 行（material_match/prematch/price/data_quality/query） | 40% |
| 模型层（v6_code/project_meta/indicator_result/code_match_cache） | ~300 行 | ~200 行（boq_item/import_batch/material_dict/audit_log 参考） | 40% |
| API 层（indicator_api） | ~300 行 | ~200 行（query/import_api 框架） | 40% |
| 前端层（indicator 页面 + 编码匹配复核） | ~800 行 | ~500 行（base/match/price 页面框架 + ECharts） | 38% |
