# V6 编码方案说明

> 对齐湘标 2.0，E/Q/D 三套独立 8 位编码体系
> 来源：豆包对话「工程量单价指标汇总及经济指标编码更新」

---

## 一、编码结构

```
指标级别码 (1 位) + 专业分类码 (1 位) + 指标分类码 (1 位) + 指标名称码 (4 位) + 计算口径码 (1 位)
```

总长度：8 位

### 各段位说明

| 段位 | 长度 | 含义 | 示例 |
|---|---|---|---|
| 指标级别码 | 1 位 | 指标级别（如 5=分部工程级） | 5 |
| 专业分类码 | 1 位 | 专业分类（A=房建/R=轨道/M=修缮/T=轨道改造） | A |
| 指标分类码 | 1 位 | 指标分类（E=经济/Q=工程量/D=单价） | E |
| 指标名称码 | 4 位 | 指标名称拼音首字母 | GJBS=钢筋 |
| 计算口径码 | 1 位 | 计算口径（US=按建筑面积等） | S |

### 编码示例解析

`5AEGFJBS`：
- 5 = 分部工程级
- A = 房屋建筑工程
- E = 经济指标编码
- GJBS = 钢筋（GangJin BiaoSun？实际为拼音首字母缩写）
- S = 计算口径

## 二、三类编码（E/Q/D）

### E 编码 — 经济指标编码
- 用途：按分部汇总合价
- 分组：按 E 编码分组统计分部合价
- 输出：经济指标（元/㎡）= 分部合价 ÷ 建筑面积 S

### Q 编码 — 工程量指标编码
- 用途：汇总物理工程量
- 分组：按 Q 编码分组统计分部总工程量
- 输出：工程量指标 = 分部总工程量 ÷ 建筑面积 S

### D 编码 — 单价指标编码
- 用途：计算分部加权平均单价
- 分组：按 D 编码分组统计分部总合价和总工程量
- 输出：加权平均单价指标 = 分部总合价 ÷ 分部总工程量

### 关键规则
1. **E/Q/D 三套编码独立**：不可混用，同一个清单行同时分配 E/Q/D 编码
2. **按各自编码分组统计**：E 按 E 编码分组；Q 按 Q 编码分组；D 按 D 编码分组
3. **名称码共享**：三类编码（E/Q/D）名称码共享，实现"一键切换"
4. **同名称分部编码不同**：同一个分部的 E/Q/D 编码不同（如钢筋 E=5AEGFJBS，Q=5AQGJBS，D=5ADGJBS）

## 三、专业分类码

| 码 | 专业 | 编码数量 | 包含分部 |
|---|---|---|---|
| **A** | 房屋建筑工程（房建） | 93 个 | 建筑/装饰/安装，纳入房建下的单位工程范畴 |
| **R** | 城市轨道交通工程 | 8 个 | 区间/轨道/车站/通信信号/供电/智能化/机电/其他 |
| **M** | 房屋修缮工程 | 10 个 | 拆除/土方/桩基/混凝土/钢结构/钢筋/砌体/装饰/安装修缮/室外修缮 |
| **T** | 城市轨道交通运营改造工程 | 4 个 | 结构装饰/轨道/机电设备/其他 |

### 安装工程的特殊处理
- 遵循湘标 2.0 规定，纳入房建（A）下的单位工程范畴
- 不再独立设码
- 安装工程编码示例：变配电 5AEBPDTS、照明动力 5AEVMDLS、喷淋 5AEPUMHS、信息网络 5AEXXWLS

## 七、V6 方案关键变化（vs V4）

| 变化项 | V4 | V6（湘标 2.0） |
|---|---|---|
| 经济指标粒度 | 二级分类归并（30 个） | 分部工程级（93 个） |
| 安装工程专业码 | 独立设码 | 纳入房建（A）下的单位工程范畴 |
| 定位机制 | 单码定位 | 指标编码 + 国标清单编码双码定位 |
| 编码切换 | 需手动切换 | 三类编码名称码共享，一键切换 |

### 双码定位机制
- 新增"指标编码 + 国标清单编码"双码定位机制
- 解决同一分部下多清单项目的唯一性问题
- 每条清单同时有：国标清单编码（9/12 位）+ E/Q/D 指标编码（8 位）

## 八、编码字典入库规划

### 数据结构
```python
# data/v6_code_dict.py 纯函数
V6_CODE_DICT = {
    "E": {  # 经济指标编码
        "5AEGFJBS": {"name": "钢筋工程", "category": "建筑", "unit": "元/㎡"},
        ...
    },
    "Q": {  # 工程量指标编码
        "5AQGJBS": {"name": "钢筋工程", "category": "建筑", "unit": "t/㎡"},
        ...
    },
    "D": {  # 单价指标编码
        "5ADGJBS": {"name": "钢筋工程", "category": "建筑", "unit": "元/t"},
        ...
    },
}
```

### 入库任务
1. 整理完整的 E/Q/D 编码字典（建筑 21 + 装饰 20 + 安装 56 = 97 条 × 3 类 = 291 条编码）
2. 编写 `data/v6_code_dict.py` 纯函数（零框架依赖，可 pure_tests 测试）
3. 编写 `models/v6_code.py` 编码表（支持用户扩展/版本化管理）
4. 编写编码管理 API（查询/新增/修改/版本管理）
5. pure_tests 覆盖：编码查询、E/Q/D 分离、名称码共享、同名称分部编码不同

### 编码匹配策略
1. **精确匹配**：根据项目名称 + 项目特征精确匹配编码字典
2. **模糊匹配**：使用 rapidfuzz + TF-IDF 进行模糊匹配（复用 M3 匹配算法）
3. **人工复核**：未匹配或低置信度匹配项标记【待补编码】，人工复核
4. **学习机制**：人工复核结果反馈到编码匹配算法，越用越准（复用学习引擎 v3）
