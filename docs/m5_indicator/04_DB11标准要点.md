# DB11 标准要点

> DB11/T 1711-2019《建设工程造价技术经济指标采集标准》要点摘录
> 用于 M5 自动指标生成的标准依据

---

## 一、标准概述

- **标准编号**：DB11/T 1711-2019
- **标准名称**：建设工程造价技术经济指标采集标准
- **适用地区**：北京市（地方标准，其他地区可参考）
- **适用范围**：房屋建筑工程、城市轨道交通工程、房屋修缮工程等
- **核心内容**：工程造价技术经济指标的采集内容、采集方法、精度要求、表格格式

---

## 二、工程类型划分（表 3.0.1）

### 2.1 一级分类

| 码 | 工程类型 | 说明 |
|---|---|---|
| A | 房屋建筑工程 | 住宅、公共建筑、工业建筑等 |
| R | 城市轨道交通工程 | 地铁、轻轨等 |
| M | 房屋修缮工程 | 既有建筑修缮、改造 |
| T | 城市轨道交通运营改造工程 | 既有轨道线路改造 |

### 2.2 二级/三级分类
- 房屋建筑工程：建筑工程、装饰工程、安装工程
- 安装工程：采暖、给排水、消防、变配电、照明、动力、通风空调、智能化、防雷接地
- 城市轨道交通工程：区间、轨道、车站、通信信号、供电、智能化、机电、其他

## 三、指标精度要求（3.0.4）

### 3.1 经济指标

| 指标 | 精度 | 单位 |
|---|---|---|
| 单方造价（经济指标） | 保留 2 位小数 | 元/㎡ |
| 占总造价比例 | 保留 4 位小数后转为百分比 | % |
| 分部合价 | 保留 2 位小数 | 元 |

### 3.2 工程量指标

| 指标 | 精度 | 单位 |
|---|---|---|
| 单方工程量（工程量指标） | 保留 3 位小数 | 原单位/㎡（t/㎡、m³/㎡等） |
| 分部总工程量 | 保留 3 位小数 | 原单位 |

### 3.3 单价指标

| 指标 | 精度 | 单位 |
|---|---|---|
| 加权平均单价（单价指标） | 保留 2 位小数 | 元/原单位（元/t、元/m³等） |
| 分部总合价 | 保留 2 位小数 | 元 |
| 分部总工程量 | 保留 3 位小数 | 原单位 |

## 六、指标计算口径

### 6.1 经济指标（单方造价）
```
单方造价 = 分部总合价 ÷ 建筑面积
```
- 建筑面积为核心分母，不可为 0
- 分部总合价为该分部下所有清单合价之和
- 占总造价比例 = 分部总合价 ÷ 项目分部分项总合价

### 6.2 工程量指标（单方工程量）
```
单方工程量 = 分部总工程量 ÷ 建筑面积
```
- 多计量单位分部取合价占比最大的单位汇总
- 其他单位的工程量单独列示，不纳入主单位汇总

### 6.3 单价指标（加权平均单价）
```
加权平均单价 = 分部总合价 ÷ 分部总工程量
```
- 采用加权平均，非简单平均
- 与经济指标/工程量指标满足 Q×D≈E 校验关系

---

## 七、Q×D≈E 校验关系

### 7.1 理论关系
```
经济指标 E = 工程量指标 Q × 单价指标 D
```

### 7.2 偏差判定
| 偏差率 | 判定 | 说明 |
|---|---|---|
| ≤ 1% | 合格 | 正常通过 |
| 1% ＜ 偏差 ≤ 5% | 注意 | 多计量单位混合统计，备注说明 |
| ＞ 5% | 异常 | 回溯编码挂接/分组口径，人工复核 |

### 7.3 偏差产生原因
- 多计量单位混合（同一 D 编码下多种单位）
- 编码挂接错误（E/Q/D 编码分配错误）
- 分组口径不一致（同名称分部 E/Q/D 编码分组范围不同）
- 合价计算误差（清单合价 = 工程量 × 综合单价 的累计误差）
