> 来源：豆包对话「工程量单价指标汇总及经济指标编码更新」

## 阶段 1：数据清洗

### 目标
从原始工程量清单 Excel 中提取有效分部分项清单条目，清洗数据，标记异常。

### 步骤

#### 1.1 过滤无效行
- **空行**：所有字段为空的行
- **合计行**：项目名称含"合计""总计""小计""累计"
- **备注行**：项目名称含"注：""说明：""备注：""以下空白"
- **措施项目/规费/税金行**：根据工程类型判断是否纳入（默认只保留分部分项清单）

#### 1.2 字段标准化
- **项目名称**：去除前后空格、统一全角/半角、去除不可见字符
- **项目特征**：去除前后空格、统一分隔符（逗号/分号/顿号）
- **计量单位**：修正大小写（M3→m³、M2→㎡、M→m）、去除空格、统一符号

#### 1.3 数据类型转换
- 工程量：转为 float，非数值标记异常
- 综合单价：转为 float，非数值标记异常
- 合价：转为 float，非数值标记异常

#### 1.4 合价校验
```
计算合价 = 工程量 × 综合单价
误差率 = |实际合价 − 计算合价| ÷ 计算合价 × 100%
误差率 > 0.5% → 标记异常清单行
```

### 输出
- `valid_items`：有效清单条目列表
- `abnormal_items`：异常清单条目列表（含异常原因）

### 可复用组件
- `data/field_spec.py`：字段分层定义（A/B/C 类）
- `data/aliases.py`：表头别名映射（复用 M2 字段映射模板）
- `data/unit_normalize.py`：单位归一化（复用现有纯函数）

## 阶段 2：项目元数据录入

### 目标
录入项目基础元数据，确定建筑面积 S（全部指标的核心分母）。

### 必填字段

| 字段 | 说明 | 校验规则 |
|---|---|---|
| 工程名称 | 项目全称 | 非空 |
| 建筑面积 S | 单位：㎡ | > 0，不可为 0（核心分母） |
| 工程类型 | 房建/轨道/修缮/轨道改造 | 对应 V6 专业码 A/R/M/T |
| 结构类型 | 框架/剪力墙/框架剪力墙等 | 非空 |
| 计价依据 | 定额/清单/市场化 | 非空 |
| 造价类型 | 概算/预算/招标控制价/结算 | 非空 |
| 开竣工日期 | 开工/竣工日期 | 格式校验 |
| 合同信息 | 合同编号/合同价 | 可选 |

### 关键规则
- **建筑面积 S 是全部指标的分母**：S=0 时终止计算，抛出错误
- **工程类型决定专业码**：房建=A，轨道=R，修缮=M，轨道改造=T
- **元数据与 import_batch 关联**：一个批次对应一个单位工程，可从批次信息自动填充

### 可复用组件
- `models/import_batch.py`：批次表（含工程名称、建筑面积等字段，可扩展）
- `app/api/import_api.py`：导入时录入的批次信息

## 阶段 3：编码匹配

### 目标
根据清单【项目名称 + 项目特征】匹配 V6 编码字典，为每条清单分配 E/Q/D 三套编码。

### 步骤

#### 3.1 编码匹配策略
1. **精确匹配**：项目名称 + 项目特征精确匹配编码字典
2. **模糊匹配**：使用 rapidfuzz + TF-IDF 进行模糊匹配（复用 M3 匹配算法）
3. **置信度排序**：Top-5 候选，按置信度排序
4. **自动确认**：置信度 ≥ 90% 自动分配编码
5. **人工复核**：置信度 < 90% 或未匹配，标记【待补编码】

#### 3.2 编码分配规则
- 每条清单同时分配 E 编码、Q 编码、D 编码
- E/Q/D 三套编码独立，不可混用
- 同名称分部的 E/Q/D 编码不同（名称码共享，指标分类码不同）
- 编码来源 V6 编码方案，对齐湘标 2.0

#### 3.3 编码完整性检查
- 所有有效清单必须分配 E/Q/D 编码
- 未匹配编码条目标记【待补编码】
- 人工复核后回填编码
- 不允许空编码直接进入统计

### 输出
- `coded_items`：已分配 E/Q/D 编码的清单列表
- `pending_code_items`：待补编码清单列表

### 可复用组件
- `services/material_match_service.py`：物料匹配服务（三算法融合，可复用匹配算法）
- `data/tfidf_matcher.py`：TF-IDF 语义匹配（纯函数，可复用）
- `data/learning_engine_v3.py`：学习引擎 v3（编码匹配结果可反馈学习）
- `services/prematch_service.py`：后台预匹配（可复用预匹配机制）

## 阶段 4：指标计算

### 目标
按 E/Q/D 编码分组，计算经济指标、工程量指标、单价指标。

### 步骤

#### 4.1 E 经济指标计算（按 E 编码分组）
```
分部合价 = Σ(该 E 编码下所有清单的合价)
经济指标（元/㎡） = 分部合价 ÷ 建筑面积 S
占总造价比例 = 分部合价 ÷ 项目分部分项总合价 × 100%
```
精度：经济指标保留 2 位小数；占比保留 4 位小数后转为百分比

#### 4.2 Q 工程量指标计算（按 Q 编码分组）
```
分部总工程量 = Σ(该 Q 编码下所有清单的工程量)
工程量指标 = 分部总工程量 ÷ 建筑面积 S
```
精度：工程量指标保留 3 位小数；单位：原清单单位/㎡

多计量单位处理：取合价占比最大的单位汇总，其他单位单独列示

#### 4.3 D 单价指标计算（按 D 编码分组，加权平均）
```
分部总合价（D 组） = Σ(该 D 编码下所有清单的合价)
分部总工程量（D 组） = Σ(该 D 编码下所有清单的工程量)
加权平均单价指标 = 分部总合价 ÷ 分部总工程量
```
精度：单价指标保留 2 位小数；单位：元/原清单单位

### 输出
- `e_indicators`：E 经济指标汇总（按 E 编码分组）
- `q_indicators`：Q 工程量指标汇总（按 Q 编码分组）
- `d_indicators`：D 单价指标汇总（按 D 编码分组）

### 可复用组件
- `data/price_calc.py`：单价计算纯函数（可复用加权平均逻辑）
- `data/quality_metrics.py`：质量指标纯函数（可复用统计逻辑）
- `services/price_service.py`：单价分析服务（可复用聚合统计逻辑）

## 阶段 5：偏差校验

### 目标
校验 Q×D≈E，标记合格/注意/异常项，回溯异常根因。

### 步骤

#### 5.1 偏差率计算
```
理论经济指标 = Q × D
偏差率 = |Q×D − E| ÷ E × 100%
```

#### 5.2 三级判定
| 偏差率 | 判定 | 处理 |
|---|---|---|
| ≤ 1% | ✅ 合格 | 正常通过 |
| 1% ＜ 偏差 ≤ 5% | ⚠️ 注意 | 备注说明（多计量单位混合统计） |
| ＞ 5% | ❌ 异常 | 回溯原始清单，检查编码挂接/分组口径 |

#### 5.3 异常回溯
- **编码挂接错误**：检查 E/Q/D 编码分配是否正确
- **分组口径不一致**：检查同名称分部的 E/Q/D 编码分组范围是否一致
- **多计量单位混合**：检查 D 编码下是否存在多种计量单位
- **合价计算误差**：检查合价校验标记的异常清单

### 输出
- `deviation_report`：偏差校验报告（含合格/注意/异常项、根因分析）

### 可复用组件
- `services/data_quality_service.py`：数据质量服务（可复用质量校验/异常标记逻辑）
- `data/quality_metrics.py`：质量指标纯函数（可复用校验逻辑）

## 阶段 6：成果输出

### 目标
生成完整的 Excel 成果文件，包含编码明细表、三类指标汇总表、DB11 标准 Sheet 集、公司台账、校验报告。

### 输出物清单

#### 6.1 编码明细表
- 逐条清单挂 E/Q/D 编码
- 字段：序号｜子分部｜国标清单编码｜项目名称｜项目特征｜计量单位｜工程量｜综合单价｜合价｜E编码｜Q编码｜D编码｜工程量指标｜工程量指标单位｜单价指标｜单价指标单位

#### 6.2 三类指标汇总表
- E/Q/D 按分部名称做横向合并
- 字段：分部名称｜E编码｜Q编码｜D编码｜经济指标（元/㎡）｜工程量指标｜工程量指标单位｜单价指标｜单价指标单位｜偏差率｜判定

#### 6.3 DB11 标准成果 Sheet 集
1. **项目概况**：元数据、总造价、建筑面积、核心汇总指标
2. **房屋建筑安装工程特征描述表（表 4.2.1）**：工程基本信息、结构、装饰、安装、室外、措施项目特征
3. **单方造价表（建筑装饰表 4.2.6）**：E 编码分组结果，增加【经济指标编码 E】列
4. **单方造价表（安装表 4.2.7）**：按采暖/给排水/消防/变配电/照明/动力/通风空调/智能化/防雷接地系统分类
5. **主要工程量表（表 4.2.10）**：Q 编码分组结果，增加【工程量指标编码 Q】列
6. **单价指标表（扩展表）**：D 编码分组结果，增加【单价指标编码 D】列
7. **总投资指标采集表（附录 A.0.1）**：工程费用、工程建设其他费、预备费

#### 6.4 公司台账（项目情况一览表）
- 映射项目元数据
- 增加【对应专业码】（V6 专业码 A/R/M/T/R）

#### 6.5 校验报告
- 指标精度校验
- Q×D 偏差校验（合格/注意/异常项清单）
- 编码完整性校验
- 异常项根因分析

### 最终校验
1. 逐条核对编码明细表：无空 E/Q/D 编码；异常清单全部完成复核
2. 核对汇总求和：各分部合价求和 = 项目分部分项总合价
3. 校验报告归档：记录合格、注意、异常项，异常项写明根因
4. 输出完整 Excel 成果文件，所有 Sheet 命名与 V6 方案保持一致

### 可复用组件
- `app/api/query.py`：导出功能（可复用 Excel 导出框架）
- `services/query_service.py`：查询服务（可复用数据查询逻辑）
- `data/cost_catalog_gate.py`：成本目录闸门纯函数（可复用数据聚合逻辑）

## 流程依赖关系

```
阶段1（数据清洗）
  ↓ 输出 valid_items
阶段2（元数据录入）
  ↓ 输出 project_meta（含 area S）
阶段3（编码匹配）
  ↓ 输出 coded_items（含 E/Q/D 编码）
阶段4（指标计算）
  ↓ 输出 e/q/d_indicators
阶段5（偏差校验）
  ↓ 输出 deviation_report
阶段6（成果输出）
  ↓ 输出 Excel 成果文件
```

### 可并行环节
- 阶段 1 和阶段 2 可并行（数据清洗与元数据录入无依赖）
- 阶段 4 的 E/Q/D 三类指标计算可并行（按各自编码分组，无依赖）
- 阶段 6 的各 Sheet 生成可并行

### 人工介入点
- 阶段 3：低置信度编码匹配需人工复核
- 阶段 5：异常项需人工确认根因
- 阶段 6：最终成果需人工审核确认
