## 二、编码后清单明细表

### 2.1 表头结构（两行）

**第 1 行**（跨列居中）：
| 基本信息（跨 8 列） | 编码信息（跨 3 列） | 工程量指标（跨 2 列） | 单价指标（跨 2 列） |
|---|---|---|---|

**第 2 行**（具体字段）：
| 序号 | 子分部 | 国标清单编码 | 项目名称 | 项目特征 | 计量单位 | 工程量 | 综合单价 | 合价 | E编码 | Q编码 | D编码 | 工程量指标 | 工程量指标单位 | 单价指标 | 单价指标单位 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

### 2.2 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| 序号 | int | 清单序号，从 1 开始 |
| 子分部 | str | 子分部名称（V6 编码对应名称） |
| 国标清单编码 | str | 9 位或 12 位国标清单编码 |
| 项目名称 | str | 清单项目名称 |
| 项目特征 | str | 清单项目特征描述 |
| 计量单位 | str | 标准化后的计量单位（m³、㎡、t 等） |
| 工程量 | float | 清单工程量，保留 3 位小数 |
| 综合单价 | float | 清单综合单价，保留 2 位小数 |
| 合价 | float | 清单合价 = 工程量 × 综合单价，保留 2 位小数 |
| E编码 | str | 经济指标编码（8 位，如 5AEGFJBS） |
| Q编码 | str | 工程量指标编码（8 位，如 5AQGJBS） |
| D编码 | str | 单价指标编码（8 位，如 5ADGJBS） |
| 工程量指标 | float | 该清单所属分部的工程量指标（保留 3 位小数） |
| 工程量指标单位 | str | 原清单单位/㎡（如 t/㎡、m³/㎡） |
| 单价指标 | float | 该清单所属分部的加权平均单价指标（保留 2 位小数） |
| 单价指标单位 | str | 元/原清单单位（如元/t、元/m³） |

### 2.3 格式要求
- 分部标题行：绿色背景，加粗字体，跨列居中
- 异常清单行：黄色背景标记（合价误差 > 0.5%）
- 待补编码行：红色背景标记（E/Q/D 编码为空）
- 数值列：右对齐
- 文本列：左对齐

## 三、三类指标汇总表

### 3.1 表头结构

| 分部名称 | E编码 | Q编码 | D编码 | 经济指标（元/㎡） | 占比（%） | 工程量指标 | 工程量指标单位 | 单价指标 | 单价指标单位 | 偏差率（%） | 判定 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

### 3.2 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| 分部名称 | str | 分部工程名称（如钢筋工程、混凝土工程） |
| E编码 | str | 经济指标编码 |
| Q编码 | str | 工程量指标编码 |
| D编码 | str | 单价指标编码 |
| 经济指标（元/㎡） | float | 分部合价 ÷ 建筑面积，保留 2 位小数 |
| 占比（%） | float | 分部合价 ÷ 项目分部分项总合价 × 100%，保留 2 位小数 |
| 工程量指标 | float | 分部总工程量 ÷ 建筑面积，保留 3 位小数 |
| 工程量指标单位 | str | 原清单单位/㎡ |
| 单价指标 | float | 分部总合价 ÷ 分部总工程量（加权平均），保留 2 位小数 |
| 单价指标单位 | str | 元/原清单单位 |
| 偏差率（%） | float | \|Q×D − E\| ÷ E × 100%，保留 2 位小数 |
| 判定 | str | 合格/注意/异常（三级判定） |
| 备注 | str | 异常原因说明（多计量单位混合等） |

### 3.3 排序规则
- 默认按经济指标（元/㎡）降序排列
- 可按占比、工程量指标、单价指标等列排序

### 3.4 格式要求
- 合格行：白色背景
- 注意行：黄色背景
- 异常行：红色背景
- 合计行：灰色背景，加粗字体，显示项目分部分项总合价、总经济指标、总占比 100%
