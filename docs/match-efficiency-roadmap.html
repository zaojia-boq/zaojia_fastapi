10万条数据匹配确认效率优化路径

从人工逐条确认 → 自动确认 + 学习机制，目标：人工确认量降低 80%+
⚠️ 当前算法瓶颈（10万条数据下）
匹配复杂度
O(N×M)
10万清单项 × 1万字典 = 10亿次 rapidfuzz 计算，约需 2-4 小时
人工确认量
100%
高置信阈值 ≥98 太严格，绝大多数条目需人工逐条确认
无学习机制
0%
人工确认结果不反哺算法，同样的错误反复出现
第一阶段：立即可用 1-2 周 · 不改架构
⚡
降低自动确认阈值 P0
高置信阈值从 ≥98 降至 ≥90，分差 >15 自动确认。预计 60-70% 条目可自动确认，无需人工。
人工量 ↓60%
🔄
后台异步预匹配 P0
导入完成后后台异步预计算所有匹配结果，人工只确认中等置信。匹配从"实时计算"变为"预计算+缓存"。
响应 ↓90%
🏷️
按一级分类预过滤 P1
先根据项目类型/清单项特征粗分类到一级目录，再在子集中匹配。候选集从 1万 → 1-2千，匹配速度提升 5-10 倍。
速度 ↑5x
📚
同义词自动扩展 P1
人工确认时，将清单项名称作为同义词自动加入物料字典。下次相同名称直接命中，无需再确认。
重复 ↓50%
第二阶段：算法升级 1-2 月 · 引入向量检索
🔍
TF-IDF + 余弦相似度 P0
替代 rapidfuzz 编辑距离，更适合中文长文本。预计算 TF-IDF 向量，匹配复杂度从 O(N×M) 降至 O(N×log M)。
速度 ↑20x
🚀
FAISS 向量检索引擎 P0
Facebook 开源的向量检索库，支持亿级数据毫秒级检索。10万条数据匹配从小时级降至秒级。
速度 ↑100x
🧠
学习机制：权重自适应 P1
人工确认结果作为训练数据，自动调整名称/规格/分类的权重。确认越多，算法越准，自动确认率持续提升。
准确率 ↑
⚠️
异常检测与低质量识别 P1
自动识别名称不规范、单位异常、价格离群的低质量数据，标记为"需人工审核"，避免污染匹配结果。
质量 ↑
第三阶段：智能化 3-6 月 · LLM + 主动学习
🤖
LLM 语义理解辅助 P1
用大模型做语义理解和分类建议，特别是针对非标名称、缩写、行业术语。LLM 给出建议 + 置信度，人工最终确认。
非标 ↑
🎯
主动学习：最优样本推荐 P1
系统主动推荐"最有学习价值"的样本给人工确认（如模型不确定的边界案例），最大化每次人工确认的学习效率。
效率 ↑3x
🕸️
物料知识图谱 P2
建立物料之间的关系网络（替代关系、包含关系、上下游关系），支持"类似物料推荐"和"替代方案查询"。
深度 ↑
🔄
全流程自动化流水线 P2
从 Excel 导入 → 自动清洗 → 自动匹配 → 自动标准化 → 异常人工审核，全流程自动化。人工只处理 5-10% 的异常案例。
人工 ↓90%
